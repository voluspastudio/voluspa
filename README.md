# VP Studio

An independent visual research archive. Plain HTML, CSS and JavaScript: no build step.

- `index.html`: the current cover (an open spread)
- `archive/`: the Chromatic Index
- `research/`, `studio/`, `about/`: section pages
- `assets/content.js`: **edit this** to change the current issue text and the archive records
- `vercel.json`: clean URLs (`/archive` instead of `/archive/index.html`)

Every push to `main` redeploys on Vercel once the project is imported.
